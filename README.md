# Rasa-Chatbot
Proyecto para la creación del chatbot Luna con Rasa para el ABP de Patata Team.

# Precaución
Cada vez que se quiera usar la terminal para trabajar en el proyecto (entrenar al asistente, por ejemplo), se deberá introducir el comando ".venv\Scripts\activate" desde la carpeta "my-rasa-assistant".

## Actualizar dependencias

`pipreqs ./actions --force`

## Instalar dependencias

`pip install -r ./actions/requirements.txt`
